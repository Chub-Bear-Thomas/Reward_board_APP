《冒险者公会·每日悬赏任务栏》软件需求规格说明书
1. 项目概述
1.1 项目名称
冒险者公会·每日悬赏任务栏（Adventurer’s Guild Daily Quest Board）

1.2 项目目标
打造一款融合日式 RPG 冒险风格的每日待办事项管理工具。这是一款桌面应用，软件以“冒险者公会悬赏任务栏”为视觉主题，将日常工作、学习或生活任务包装成悬赏委托，通过完成任务获取经验值与自定义奖励，驱动用户以游戏化方式高效完成每日未完成事项。

1.3 目标用户
喜欢游戏化激励、厌倦传统待办清单的用户

希望通过 RPG 等级成长获得成就感的用户

需要每日提醒避免遗漏重要工作的职场人、学生或自由职业者

1.4 核心玩法概念
用户扮演一名冒险者，在公会任务板上接取每日悬赏（待办任务）

任务有明确的完成时限，逾期则委托失败

完成任务可领取自定义奖励物品，并获得经验值

经验值累积用于提升冒险者等级，解锁称号、新主题边框等

整体界面模仿日式奇幻公会中的羊皮纸布告栏，强化沉浸体验

2. 功能需求
2.1 冒险者身份
用户可以设定自己的冒险者昵称（默认“无名冒险者”）

可选择头像（提供预设的冒险者头像库，或使用本地图片）

显示当前冒险者等级、经验条、称号

等级提升时触发专属动画（如光效、升级音效）

2.2 悬赏任务管理（每日任务板）
2.2.1 创建任务
用户可自由创建悬赏委托，需包含以下字段：

任务标题（必填）：简明概括任务内容，如“讨伐拖延大魔王”

任务描述（选填）：更详细的说明，如“完成季度报告初稿”

难度等级（可选）：D / C / B / A / S，影响默认经验值区间

完成期限：日期 + 具体时刻（例如 2026-06-06 18:00）

默认设置为今日 23:59，体现“每日未完成工作”的属性

允许设定未来某一日期，但任务板只突出显示今日待完成委托

奖励物品：用户可自由添加一项或多项奖励（见 2.4）

经验值奖励：可手动输入，或根据难度自动填充（例如 D=50exp, C=100exp, B=200exp, A=400exp, S=800exp）

惩罚模式（可选）：逾期是否扣除经验（默认关闭，高级冒险者可手动开启）

2.2.2 任务状态与流转
任务包含以下状态，并在悬赏板上以视觉区分：

待接取：已创建但未确认开始，点击“接受委托”后变为进行中

进行中：已接取且未逾期，显示剩余时间倒计时

已完成：在期限前手动点击“完成委托”，获得奖励与经验

已失败：超过期限未完成，标记“失败”，不获得任何奖励（若开启惩罚则扣经验）

每日 0 点系统自动检测：所有处于“待接取”或“进行中”且截止日期为昨天及之前的任务，统一变更为“已失败”。

2.2.3 任务板展示
主界面仿照悬赏任务栏，背景为做旧木板与羊皮纸纹理

每个任务以一张悬赏令卡片呈现，包含：

委托标题（哥特或手写风格字体）

委托人标志（可随机生成 NPC 名字或使用固定公会纹章）

难度星级

剩余时间（动态倒计时：剩余 3小时 24分）

悬赏奖励（金币图标/自定义物品图标）

状态印记（“NEW”、“IN PROGRESS”、“COMPLETE”、“FAILED”）

支持筛选显示：仅今日悬赏 / 全部 / 已完成 / 已失败

点击悬赏令可展开详情面板，进行编辑、接受、完成或放弃操作

2.2.4 每日未完成提醒
桌面通知（使用系统通知 API）：

早间集结通知：每日可在设定时间（如 8:00）弹出，提示“公会布告栏已更新，今日还有 N 个委托等待冒险者！”

截止预警：任务期限前 30 分钟、15 分钟、5 分钟分别提醒

通知文案具有 RPG 风格，如“委托【击败拖延兽】将在 30 分钟后失效！”

提醒开关可全局控制，也可针对单个任务静音

2.3 任务板视觉风格（日式冒险公会风格）
主色调：羊皮纸米黄、深棕木纹、暗金镶边、深红丝绒

字体：使用衬线字体或日系哥特体（如中文可使用“站酷文艺体”、“思源宋体”重黑）

装饰元素：

木板底纹、钉子、皮质扣带

任务卡带有火漆印章、羽毛笔图标

任务状态用不同颜色的戳记（如“完成”为绿色印戳，“失败”为暗红叉形印戳）

整体布局：顶部为冒险者状态栏，中部为可横向滚动的悬赏令列表，底部为功能按钮（创建委托、背包、日志）

2.4 自定义奖励物品
每项任务可添加任意数量的自定义奖励物品

每个奖励物品包含：

名称（如“贤者之书碎片”、“猫耳发箍”、“今日奶茶券”）

图标：预设 emoji 库或上传图片（推荐使用 Twemoji 或本地 SVG）

数量（1~999）

完成委托后，物品自动存入 “冒险者背包”

背包界面可查看所有已获取的奖励，支持手动丢弃或分类查看

奖励纯粹为游戏化收藏，无真实购买功能

2.5 经验值与冒险者等级系统
2.5.1 经验获取与扣除
完成任务后，立即获得该任务设定的经验值

若开启惩罚，任务失败扣除对应经验（可设为基础经验的 20%，若经验不足则扣至 0 不掉级）

每日连续完成所有今日委托可获得额外“全清奖励”经验加成（可配置）

2.5.2 等级体系
建议预设阶梯（可后续自定义）：

Lv1 见习冒险者（0 exp）

Lv5 初级冒险者（累计 500 exp）

Lv10 独当一面的冒险者（累计 2000 exp）

Lv15 公会精英（累计 5000 exp）

Lv20 高阶冒险者（累计 12000 exp）

Lv30 英雄级冒险者（累计 30000 exp）

Lv50 传说级冒险者（累计 80000 exp）

更高等级由公式动态生成：所需经验 = 100 × level² - 50 × level + 200

升级时弹出特效提示，并解锁对应称号，称号显示在昵称旁。解锁新等级后，悬赏令边框颜色或公会纹章发生变化。

2.5.3 等级带来的增益（非必需但增强趣味）
达到特定等级可解锁额外的主题皮肤（如“暗夜公会”、“龙巢任务板”）

可提高每日可同时接取的委托数上限（默认 5 个，每 10 级 +1）

解锁背包格子扩展

2.6 历史与统计
冒险日志：按日期记录已完成/失败任务列表，以及当日经验值变动

数据统计面板：

累计完成任务数、失败任务数

当前连续完成任务天数（显示火焰图标）

总获得经验值、最高单日经验

最常获得的奖励物品

统计内容可增强成就感，鼓励每日坚持

2.7 数据持久化与同步（第一期可仅本地）
所有任务、背包、等级数据存储于本地（建议使用 IndexedDB 或 localStorage 结构化 JSON）

提供数据导出/导入功能（JSON 文件），方便备份或迁移

未来可选增加云端同步（初期暂不实现）

3. 界面原型要求
3.1 主界面 – 悬赏公告栏
顶部木纹横条：显示“冒险者公会·悬赏栏”，右侧为冒险者头像、昵称、等级及经验条

中央区域：横向排列悬赏令卡片（今日未完成高亮在前），采用卷轴展开效果，可鼠标拖拽滚动

右侧或悬浮按钮：圆形金属按钮“发布新委托”（羽毛笔图标）

底部图标导航：任务板 / 背包 / 冒险日志 / 统计

3.2 任务详情弹出框
使用羊皮纸背景的模态框，从悬赏令放大而来

显示全部任务信息、剩余时间大字体倒计时

操作按钮：“接受委托”、“完成委托”（进行中显示）、“放弃委托”（确认后标记失败）

编辑功能：仅在“待接取”状态允许修改所有字段

3.3 创建/编辑委托界面
表单式布局，带有木质纹理边框

使用下拉选择难度、日期选择器、时间选择器

奖励物品动态添加行：物品名、图标选择器（emoji 面板）、数量

实时预览卡片样式

3.4 背包界面
网格展示已获得奖励，图标+名称+数量

右键可删除（丢弃）物品

可分类筛选，如“食物”、“装备”、“素材”等（物品创建时可选择分类）

3.5 冒险日志与统计
日历热力图展示每日完成数量

列表按时间倒序显示已完成任务

统计卡片使用木牌风格

3.6 音效与动画（可选加分项）
接取任务：羊皮纸摩擦声

完成委托：金币掉落声和短促号角

失败：玻璃破碎声

升级：钟声或升级圣光音效，全屏短暂光效

4. 非功能需求
响应式设计：自适应桌面端（1280px 以上最佳）及平板横屏，移动端可简化布局

性能：任务数量在 200 条以下界面流畅，动画不卡顿

本地通知权限：首次运行时请求通知权限，并提供引导

数据安全：本地数据加密非必须，但提醒定期备份

可配置性：经验值公式、等级称号、惩罚比例等可保留在配置文件便于后期调整

5. 开发与实现建议（供 Cursor/Claude Code 使用）
为配合 Cursor 中的 Claude Code 高效生成此软件，建议采用以下技术栈与结构：

前端框架：React + TypeScript + Vite

样式方案：Tailwind CSS + 自定义主题（复古色调），配合 CSS 动画

状态管理：Zustand 或 Context API 管理用户状态、任务列表

数据持久化：使用 idb (IndexedDB 封装库) 或直接操作 localStorage

UI 组件：部分可用 Radix UI 无样式组件；自定义悬赏卡、倒计时等

通知：Web Notification API + 定时检查（setInterval 或 Service Worker）

字体：引入 Google Fonts 的日系衬线字体（如 Noto Serif JP）及中文适配

图标：自定义 SVG 图标与 Twemoji

项目结构建议
text
src/
  components/    # 任务卡、背包、统计等组件
  store/         # 状态管理
  utils/         # 经验计算、时间工具
  assets/        # 图片、音效、字体
  types/         # TypeScript 类型定义
  App.tsx
  main.tsx
Claude Code 可根据本需求文档，逐步生成完整的前端应用。可先从核心任务管理、等级系统开始，再逐步完善背包、统计与通知功能。UI 风格需严格围绕“日式冒险公会悬赏栏”进行设计，所有文案保持 RPG 语气。
