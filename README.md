# ⚔️ 冒险者公会 · 每日悬赏任务栏

**Adventurer's Guild Daily Quest Board**

> 将每日待办事项化为 RPG 悬赏委托，用游戏化方式征服你的每一天！

一个融合日式 RPG 冒险风格的待办事项管理工具。以"冒险者公会悬赏任务栏"为视觉主题，通过完成任务获取经验值与奖励，解锁等级称号与主题皮肤。

## ✨ 功能特性

### 🎯 悬赏任务系统
- **创建委托** — 设定标题、描述、难度(D/C/B/A/S)、截止期限、经验奖励
- **四态流转** — 📜待接取 → ⚔️进行中 → ✅已完成 / ❌已失败
- **自动过期检测** — 每分钟自动检查，逾期任务标记为失败
- **全清奖励** — 今日委托全部完成可获得额外 50% 经验
- **惩罚模式** — 开启后失败扣除 20% 经验值

### 🧙 冒险者成长
- **等级系统** — 从「见习冒险者」到「传说级冒险者」，共 7 档称号
- **经验公式** — `100 × Lv² - 50 × Lv + 200`，越升级越有挑战
- **主题解锁** — 每 10 级解锁新主题皮肤（暗夜公会 / 龙巢任务板 / 精灵森林）
- **连续天数** — 追踪每日连续完成任务的🔥火焰天数

### 🎒 背包 & 日志
- **背包系统** — 完成委托获得奖励物品，按分类（食物/装备/素材/消耗品/收藏品）管理
- **冒险日志** — 30 天热力图 + 历史记录，回顾你的冒险旅程
- **统计面板** — 完成率、连续天数、今日经验、Top 5 奖励等多维度数据

### 🔔 通知 & 音效
- **早间集结** — 每日定时提醒今日待完成委托
- **截止预警** — 到期前 30/15/5 分钟三次提醒
- **单任务静音** — 针对特定任务关闭通知
- **8-bit 复古音效** — 接受委托、完成任务、升级等操作均有专属音效

### 💾 数据管理
- **本地存储** — 数据保存在浏览器 localStorage
- **导入/导出** — JSON 格式一键备份与恢复
- **桌面应用** — 基于 Tauri 打包为原生桌面程序（Windows/macOS/Linux）

## 📦 安装与运行

### 环境要求
- Node.js 18+
- npm 或 pnpm

### Web 版

```bash
# 克隆仓库
git clone git@github.com:Chub-Bear-Thomas/Reward_board_APP.git
cd Reward_board_APP

# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build
```

浏览器打开 `http://localhost:5173` 即可使用。

### 桌面版 (Tauri)

```bash
# 开发模式
npm run desktop:dev

# 构建桌面应用
npm run desktop:build
```

构建产物位于 `src-tauri/target/release/` 目录。

> **注意**: 桌面版构建需要 Rust 环境，请先安装 [Rust](https://rustup.rs/)

## 🎮 使用指南

### 创建委托
点击右下角 ✒️ 按钮，填写委托信息：
- **标题** (必填) — 任务名称
- **难度** — D(★) ~ S(★★★★★)，影响经验值
- **截止期限** — 默认今日 23:59
- **奖励物品** — 完成后存入背包
- **惩罚模式** — 失败扣 20% 经验

### 任务状态流转
```
创建 → 📜待接取 → 接受 → ⚔️进行中 → 完成 → ✅已完成
                                      ↓
                                 逾期自动 → ❌已失败
```

### 等级与称号

| 等级 | 累计经验 | 称号 | 解锁 |
|------|----------|------|------|
| Lv1 | 0 | 见习冒险者 | — |
| Lv5 | 500 | 初级冒险者 | — |
| Lv10 | 2,000 | 独当一面的冒险者 | 🌙 暗夜公会主题 |
| Lv15 | 5,000 | 公会精英 | — |
| Lv20 | 12,000 | 高阶冒险者 | 🐉 龙巢任务板主题 |
| Lv30 | 30,000 | 英雄级冒险者 | 🧝 精灵森林主题 |
| Lv50 | 80,000 | 传说级冒险者 | — |
