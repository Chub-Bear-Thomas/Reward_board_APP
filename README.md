# 冒险者公会·每日悬赏任务栏

一款纯本地运行、无需网络权限的安卓游戏化每日待办工具。将用户每日未完成的事项设计为日式 RPG 冒险公会中的"悬赏委托"，通过创建任务、接受委托、完成确认、自定义奖励与经验升级闭环，以正向心理激励帮助用户管理日常事务。

## 功能特性

### 🎯 核心功能
- **悬赏任务管理**：创建、接受、完成、放弃任务
- **逾期自动检测**：每日凌晨自动检查逾期任务
- **经验值系统**：完成任务获得经验值，提升等级
- **等级称号**：1-20级，每级对应独特称号
- **并行任务限制**：根据等级限制同时进行的任务数量

### 🔔 提醒系统
- **晨间集结提醒**：每日定时提醒接取委托
- **截止预警**：任务到期前30分钟、15分钟、5分钟提醒
- **单任务静默**：可设置单个任务不提醒

### 📊 数据管理
- **完全离线**：所有数据存储在本地SQLite数据库
- **数据导出**：导出为JSON文件备份
- **数据导入**：从JSON文件恢复数据

### 🎨 界面设计
- **日式RPG风格**：木纹、羊皮纸、火漆印章主题
- **沉浸式体验**：游戏化界面设计
- **移动端优化**：针对单手操作优化

## 技术栈

- **框架**：React Native + Expo (bare workflow)
- **语言**：TypeScript
- **状态管理**：Zustand
- **数据库**：expo-sqlite (SQLite)
- **通知**：expo-notifications
- **后台任务**：expo-background-fetch + expo-task-manager
- **UI组件**：react-native-paper
- **动画**：react-native-reanimated

## 安装与运行

### 前提条件
- Node.js 18+
- npm 或 yarn
- Expo CLI
- Android Studio (用于Android开发)

### 安装步骤

1. **克隆项目**
   ```bash
   git clone <repository-url>
   cd adventurer-guild-todo
   ```

2. **安装依赖**
   ```bash
   npm install
   # 或
   yarn install
   ```

3. **启动开发服务器**
   ```bash
   npm start
   # 或
   yarn start
   ```

4. **运行应用**
   ```bash
   # Android
   npm run android
   # 或
   yarn android
   ```

### 构建APK

```bash
# 构建Android APK
expo build:android
```

## 配置说明

### 权限配置
应用需要以下权限：
- `RECEIVE_BOOT_COMPLETED`：支持重启后重新调度后台任务
- `VIBRATE`：触觉反馈
- `POST_NOTIFICATIONS`：Android 13+通知权限

**注意**：应用不需要INTERNET权限，确保完全离线运行。

### 数据库配置
使用SQLite数据库，包含以下表：
- `user`：用户信息
- `quest`：任务数据
- `notification_ids`：通知ID记录

## 使用说明

### 创建任务
1. 点击主页右下角的"+"按钮
2. 填写任务标题（必填）
3. 设置截止时间（默认为当天23:59）
4. 设置经验值（1-9999）
5. 可选：添加奖励物品（最多3个）
6. 可选：开启静默通知
7. 点击"创建委托"

### 接受任务
1. 在任务列表中找到待接取的任务
2. 点击任务卡片进入详情页
3. 点击"接受委托"按钮
4. 确认接受

### 完成任务
1. 在任务列表中找到进行中的任务
2. 点击任务卡片进入详情页
3. 点击"完成委托"按钮
4. 获得经验值奖励

### 放弃任务
1. 在任务列表中找到进行中的任务
2. 点击任务卡片进入详情页
3. 点击"放弃委托"按钮
4. 确认放弃

最大并行任务数 = 3 + 当前等级

例如：
- Lv.1：最多4个并行任务
- Lv.5：最多8个并行任务
- Lv.10：最多13个并行任务

## 数据备份与恢复

### 导出数据
1. 进入个人中心
2. 点击"设置"
3. 选择"导出数据"
4. 选择保存位置

### 导入数据
1. 进入个人中心
2. 点击"设置"
3. 选择"导入数据"
4. 选择备份文件

## 注意事项

1. **完全离线**：应用不需要网络权限，所有数据存储在本地
2. **数据备份**：请定期备份重要数据，以防数据丢失
3. **通知权限**：Android 13+需要手动授予通知权限
4. **后台任务**：后台任务可能受到系统限制，建议定期打开应用检查
5. **时间设置**：确保设备时间准确，以免影响任务截止时间判断

## 开发说明

1. 在`src/screens/`中创建新页面组件
2. 在`src/types/navigation.ts`中添加导航类型
3. 在`App.tsx`中注册新页面

## 常见问题

### Q: 为什么收不到通知？
A: 请检查：
1. 是否授予了通知权限
2. 是否在设置中关闭了通知总开关
3. 是否在任务中开启了静默通知
4. 设备是否开启了勿扰模式

### Q: 任务逾期后会怎样？
A: 逾期任务会被自动标记为"失败"状态，不会扣除经验值。

### Q: 如何修改晨间提醒时间？
A: 进入个人中心 → 设置 → 晨间提醒时间，选择新的时间即可。

### Q: 数据丢失了怎么办？
A: 如果之前有导出备份，可以通过"导入数据"功能恢复。建议定期备份重要数据。
